# Design

A quiet personal investment ledger for repeated daytime review. Warm off-white canvas, ink text, forest green actions, amber freshness warnings. The signature is the source ledger: each value sits beside its coverage and connection age. Tabular numbers, generous column alignment and thin rules make holdings easy to scan.

Use system sans-serif for controls and serif for primary page titles. Sidebar navigation on desktop becomes a horizontally scrollable labeled navigation on mobile. Reuse Preline static sidebar and responsive table structure; no Preline runtime dependency. Sources: https://preline.co/docs/components/sidebar.html and https://preline.co/docs/components/tables.html, licensed under MIT for free components (https://preline.co/license.html).

Tokens: canvas #f6f7f2, surface #fff, text #182e29, muted #56665f, accent #235d45, border #dbe2da, warning #805418. Focus outline 3px. Controls minimum 44px. Compact tables scroll within their own labeled region. No decorative imagery; charts represent actual snapshot observations only.
